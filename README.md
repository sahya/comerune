# comerune
A mobile comment viewer for Nico live streams with optional voice reading.

<p align="center">
  <img src="icon_source.png" alt="comerune" width="128" />
</p>

ニコニコ生放送のコメントを、手のひらの上で楽しむための非公式コメントビューアです。

放送のコメントをリアルタイムに取得・表示するのはもちろん、読み上げ機能も備えているので、画面を見られないときでもコメントの流れを耳で追うことができます。

> **注意**: 本アプリはドワンゴ公式のアプリではありません。ニコニコのサービス仕様変更により、予告なく動作しなくなる場合があります。また、コメントの取得にはニコニコアカウントへのログインが必要です。

---

## どんなことができるの？

**コメントをリアルタイムに取得・表示**

放送番号（lv）やURLを入力するだけで、コメントが次々と画面に流れてきます。過去コメントの取得にも対応しています。

**放送者名・番組タイトルの自動表示**

接続すると画面上部のバー（AppBar）に放送者名、タイトルバーに番組タイトルが表示されます。「いま誰の放送を見ているんだっけ？」と迷うことがありません。

**ユーザー名の解決**

コメントの横にユーザー名を表示できます。数字の羅列だったユーザーIDが、見慣れた名前に変わるだけで、コメント欄がぐっと身近に感じられるはずです。

**文字サイズの自由な調整（10〜48px）**

小さなスマホでも大きなタブレットでも、自分にちょうどいい文字サイズで読めます。視力に不安のある方にも安心して使っていただけるよう、最大48pxまで対応しました。

**ダークモード・色覚配慮テーマ**

夜間の視聴にやさしいダークモードのほか、1型・2型・3型色覚に配慮したテーマも用意しています。すべての人が快適に使えるように。

**NGユーザー管理**

コメントを長押しすると、そのユーザーの詳細やコメント履歴を確認できます。気になるユーザーはNGに登録でき、設定画面からまとめて確認・解除することもできます。

**コメントログの保存**

大事な放送のコメントは、テキストファイルとして端末に保存できます。自動保存にも手動保存にも対応。あとから振り返りたいときに便利です。

**読み上げ機能（今後の予定）**

VOICEVOXによる音声読み上げを予定しています。画面を見なくても、コメントの盛り上がりを感じ取れるようになります。

## はじめかた

### 必要なもの

- Flutter SDK 3.3.0 以上
- Android SDK
- Android 実機またはエミュレータ

### セットアップ

```bash
# リポジトリをクローン
git clone https://github.com/sahya/comerune.git
cd comerune

# 依存パッケージの取得
flutter pub get
```

### ビルド・実行

```bash
# デバッグビルド（実機/エミュレータ接続時）
flutter run

# デバッグAPKの生成
flutter build apk --debug

# リリースAPKの生成
flutter build apk --release
```

Makefileも用意しているので、こちらでも同じことができます。

```bash
make build           # デバッグAPK
make build-release   # リリースAPK
make test            # テスト実行
make check           # 静的解析 + フォーマット + テスト（まとめて）
```

### ニコニコへのログイン

コメントの取得にはニコニコアカウントへのログインが必要です。アプリを起動したら、接続先選択画面の歯車アイコン（⚙）、またはログインバナーから設定画面を開き、ニコニコにログインしてください。

## 技術的なこと

- **Flutter** で構築（Dart / Android）
- ニコニコ生放送のコメントをリアルタイムに取得・表示
- **レイヤードアーキテクチャ**: domain / application / data / presentation の4層構成
- **自動再接続**: 指数バックオフによる断線復帰
- **CI**: GitHub Actionsでフォーマット・静的解析・テストを自動実行

---

## 使いかた

1. アプリを起動して、放送番号（`lv123456789`）またはURLを入力
2. 「接続」ボタンを押すと、コメントがリアルタイムに表示されます
3. コメントを長押しすると、ユーザーの詳細情報やコメント履歴を確認できます
4. 歯車アイコンから、テーマ・文字サイズ・読み上げなどの設定を変更できます
