# comerune
A mobile comment viewer for Nico live streams with optional voice reading.

<p align="center">
  <img src="icon_source.png" alt="comerune" width="128" />
</p>

ニコニコ生放送のコメントを、手のひらの上で楽しむための非公式コメントビューアです。

放送のコメントをリアルタイムに取得・表示するのはもちろん、読み上げ機能も備えているので、画面を見られないときでもコメントの流れを耳で追うことができます。

> **注意**: 本アプリはドワンゴ公式のアプリではありません。ニコニコ側の仕様が変わると動かなくなることもあります。また、コメントの取得にはニコニコアカウントへのログインが必要です。

---

## どんなことができるの？

**コメントをリアルタイムに取得・表示**

放送番号（lv）やURLを入力するだけで、コメントが次々と画面に流れてきます。過去コメントの取得にも対応しています。

**放送者名・番組タイトルの自動表示**

接続すると画面上部のバー（AppBar）に放送者名、タイトルバーに番組タイトルが表示されます。「いま誰の放送を見ているんだっけ？」と迷うことがありません。

**ユーザー名の解決**

コメントの横にユーザー名を表示できます。数字の羅列だったユーザーIDが、見慣れた名前に変わるだけで、コメント欄がぐっと身近に感じられるはずです。

**文字サイズの自由な調整（10〜48px）**

小さなスマホでも大きなタブレットでも、自分にちょうどいい文字サイズで読めます。視力に不安のある方にも安心して使っていただけるよう、最大48pxまで対応しました。

**ダークモード・色覚配慮テーマ**

夜間の視聴にやさしいダークモードのほか、1型・2型・3型色覚に配慮したテーマも用意しています。すべての人が快適に使えるように。

**NGユーザー管理**

コメントを長押しすると、そのユーザーの詳細やコメント履歴を確認できます。気になるユーザーはNGに登録でき、設定画面からまとめて確認・解除することもできます。

**コメントログの保存**

大事な放送のコメントは、テキストファイルとして端末に保存できます。自動保存にも手動保存にも対応。あとから振り返りたいときに便利です。

**読み上げ機能（今後の予定）**

VOICEVOXによる音声読み上げを予定しています。画面を見なくても、コメントの盛り上がりを感じ取れるようになります。

## 使いかた

1. アプリを起動して、放送番号（`lv123456789`）またはURLを入力
2. 「接続」ボタンを押すと、コメントがリアルタイムに表示されます
3. コメントを長押しすると、ユーザーの詳細情報やコメント履歴を確認できます
4. 歯車アイコンから、テーマ・文字サイズなどの設定を変更できます

コメントを取得するにはニコニコアカウントでのログインが必要です。歯車アイコン（⚙）かログインバナーから設定画面を開いて、先にログインを済ませておいてください。

## 技術的なこと

FlutterとDartで書かれたAndroidアプリです。コメントの取得から表示まで、domain / application / data / presentation の4層に分けて設計しています。回線が切れても自動で再接続を試みるので、電波が不安定な場所でもわりと粘ってくれます。

CIはGitHub Actionsで回していて、フォーマット・静的解析・テストを自動でチェックしています。

Flutterで作っているので、少し手を入れればiOSアプリとしても動かせるかもしれません。
