# comerune
A mobile comment viewer for Nico live streams with optional voice reading.

  <img src="icon_source.png" alt="comerune" width="128" />
</p>

ニコニコ生放送のコメントを、手のひらの上で楽しむための非公式コメントビューアです。

> **読みかた**: 「こめるーん」（comerune）。**Comment**（コメント）と **Rune**（ルーン文字）の響きをもじった造語です。コメントが画面に書きこまれていく光景と、文字を一字ずつ刻むルーンの所作が、ふしぎと重なって見えました。「Rune」のひびきが、なんとなく好きで選んだ、というのが正直なところでもあります。

放送のコメントをリアルタイムに取得・表示するのはもちろん、読み上げ機能も備えているので、画面を見られないときでもコメントの流れを耳で追うことができます。

> **注意**: 本アプリはドワンゴ公式のアプリではありません。ニコニコ側の仕様が変わると動かなくなることもあります。また、コメントの取得にはニコニコアカウントへのログインが必要です。

---

## 主な機能

- **コメントのリアルタイム表示** — 放送番号やURLを入力するだけで、コメントが画面に流れてきます
- **放送者名・番組タイトルの自動表示** — いま誰の放送を見ているか、ひと目でわかります
- **ユーザー名の表示** — 数字のIDではなく、名前でコメントを読めます
- **表示のカスタマイズ** — 文字サイズの調整、ダークモード、色覚配慮テーマに対応しています
- **NGユーザー管理** — コメントの長押しからユーザー詳細を確認し、NGに登録できます
- **コメントログの保存** — 放送のコメントをテキストファイルとして保存できます
- **VOICEVOXによる音声読み上げ** — コメントを端末内で音声合成して読み上げます。ネットワーク不要で、初回のみ音声データのダウンロード（約160MB）が必要です。端末の性能によって応答速度が変わります（[詳細](docs/voicevox-performance-guide.md)）

## 使いかた

1. アプリを起動して、放送番号（`lv123456789`）またはURLを入力
2. 「接続」ボタンを押すと、コメントがリアルタイムに表示されます
3. 自分が配信中の番組や、フォロー中のユーザーが配信中なら、一覧から選んでそのまま接続できます
4. コメントを長押しすると、ユーザーの詳細情報やコメント履歴を確認できます
5. 歯車アイコンから、テーマ・文字サイズなどの設定を変更できます

コメントを取得するにはニコニコアカウントでのログインが必要です。歯車アイコン（⚙）かログインバナーから設定画面を開いて、先にログインを済ませておいてください。

## 技術的なこと

FlutterとDartで書かれたAndroidアプリです。コメントの取得から表示まで、domain / application / data / presentation の4層に分けて設計しています。回線が切れても自動で再接続を試みるので、電波が不安定な場所でもわりと粘ってくれます。

CIはGitHub Actionsで回していて、フォーマット・静的解析・テストを自動でチェックしています。

Flutterで作っているので、少し手を入れればiOSアプリとしても動かせるかもしれません。

### アプリ名について

フォークしたアプリを公開するときは、**「comerune」とは別の名前**で公開してください。これはお願いであると同時に、利用者を守るためのルールでもあります。同名のアプリが複数存在すると、利用者がどれが本物か判断できず混乱を招いたり、悪意ある改変版との区別がつかなくなるおそれがあります。あなたのアプリには、あなたらしい名前をつけてあげてください。
