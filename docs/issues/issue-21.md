# Issue #21: コメント表示E2Eフローの手動確認とデバッグ

Labels: v1.2, integration, testing

GitHub Issue:

Epic: #1

## Goal

Issue #15 の受け入れ基準のうち読み上げ以外をすべて通過することを実機で確認し、発見したバグを修正する。

## Scope

- **全ユーザーフロー確認**（統合仕様 §10.1〜10.5）:
  - §10.1 基本フロー: URL入力 → 接続 → コメント表示 → 停止
  - §10.2 接続失敗: 不正入力 → Snackbar → IDLE 維持
  - §10.3 自動再接続: 回線断 → RECONNECTING → 復帰（30秒以内目安）
  - §10.4 放送終了: ENDED → 再接続ボタン → 同一 lv で再開
  - §10.5 別放送切り替え: 停止 → SelectScreen → 新 lv → コメントクリア
- **エラーフロー確認**:
  - 全エラーコード（§13.1）の表示が正しいこと
  - Snackbar の表示条件（FAILED 時のみ）
- **設定反映確認**:
  - デバッグモード ON/OFF → ステータスバーの表示切替
  - 過去コメント取得件数変更 → 次回接続時のバッファ上限反映
- **発見したバグの修正**

## Non-scope

- 読み上げフロー確認（棒読みちゃん、VOICEVOX）
- 新規機能の追加
- パフォーマンスチューニング
- 自動テストの追加（手動確認のみ）

## Dependencies

- Issue #20（全コンポーネント配線）

## Acceptance Criteria

- [ ] URL 貼り付けで lv が抽出される
- [ ] 接続開始でコメントが流れる（NDGR）
- [ ] legacy 接続時に chat キーのコメントが表示される
- [ ] legacy 接続時に chat キー無しでクラッシュせず「legacy: 未対応フォーマット」が表示される
- [ ] 接続停止で確実に停止する
- [ ] Wi-Fi アイコンが状態に応じて赤/緑で切り替わる
- [ ] 新着で自動スクロール（ユーザースクロール中は停止）
- [ ] 瞬断後に自動復帰する（通常30秒以内）
- [ ] デバッグ情報が揃っている
- [ ] ~~棒読みちゃんで読み上げが動作する~~ → スキップ（グレーアウト対象）
- [ ] ~~VOICEVOX で読み上げが動作する~~ → スキップ（グレーアウト対象）
- [ ] 発見したバグがすべて修正されている

## Validation / Error Handling

- 全エラーコードの表示確認（§13.1）
- 接続失敗からの復帰が安全であること

## Test Expectations

- **unit**: なし
- **widget**: なし
- **integration**: 実機での E2E テスト（手動）。結果を GitHub Issue コメントに記録する

## Assumptions

- 実際のニコニコ生放送サーバへの接続が必要
- テスト用の放送が利用可能であること（または過去放送のアーカイブ）
- バグの規模によっては本 Issue のスコープ外とし、別 Issue を起票する場合がある

## AI実装適性

**Low** — 実機テストとデバッグが中心。実際の放送サーバへの接続が必要

## Human Approval Needed

**Yes** — 最終的な動作確認はオーナーが行う必要がある
