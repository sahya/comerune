# Issue #35: コメント整形 — 文字数制限・辞書置換・NGワード

## Goal

整形済みテキストに対して、文字数の上限制限、ニコニコ用語の辞書置換、NGワードによるスキップを適用する。
これにより、長文が延々と読まれたり、不適切なコメントが音声化されるのを防ぐ。

## Scope

### 文字数制限（仕様 Section 3.5.5）

- 最大読み上げ文字数: `maxTextLength`（デフォルト 50）
- 超過時: 先頭 N 文字 + `trimLongTextSuffix`（デフォルト「、以下省略」）

### 辞書置換（仕様 Section 3.5.6）

- `SpeechSettings.dictionaryRules` に基づき、パターン → 置換を適用
- 各ルールは `enabled` フラグで ON/OFF 可能
- パターンは正規表現

初期辞書例:

| 入力 | 読み |
|---|---|
| 初見 | しょけん |
| うぽつ | うぽつ |
| 乙 | おつ |
| kwsk | くわしく |

### NGワード（仕様 Section 3.5.7）

- `SpeechSettings.ngWords` に一致するコメントをスキップ
- 部分一致・大文字小文字不問
- 初期実装はスキップのみ（「ピー」置換は将来対応）

## Non-scope

- 辞書ルールの永続化 UI（Flutter 設定画面の Issue）
- NGワードの初期リスト提供（Q5 で確認）
- 「ピー」音差し込み
- 辞書ルールのバリデーション UI

## Dependencies

- #32（データモデル: SpeechSettings, ReplaceRule）
- #33（CommentNormalizer 骨格）
- #34（URL・記号変換が先に適用される前提）

## Acceptance Criteria

1. 50文字を超えるテキストが切り詰められ、末尾に「、以下省略」が付く
2. `maxTextLength` の設定値変更が反映される
3. 辞書ルール `{ pattern: "初見", replacement: "しょけん" }` が正しく置換される
4. `enabled: false` の辞書ルールは適用されない
5. NGワード「NG例」を含むコメントが `skipReason = "ng_word"` でスキップされる
6. NGワード判定は大文字小文字不問
7. 不正な正規表現パターンの辞書ルールがあってもクラッシュしない（スキップされる）

## Test Expectations

- **単体テスト（必須）**:
  - 文字数ちょうど50文字 → 切り詰めなし
  - 文字数51文字 → 切り詰め + 省略付与
  - 辞書置換の基本動作
  - 辞書ルール enabled=false のスキップ
  - 不正正規表現の安全なスキップ
  - NGワードによるスキップ
  - NGワードの大文字小文字不問確認
  - 空の ngWords / dictionaryRules での正常動作

## AI 実装適性

- **AI 実装に向いている**: ルールベースの変換ロジック。テストケースが書きやすい
- **人間承認ポイント**: 初期辞書ルールの内容（ニコニコ文化に依存するため、適切な読みかどうかはオーナー確認が望ましい）

## Implementation Notes

- 辞書置換で不正な正規表現が来る可能性があるため、`runCatching` で囲む（スケルトンコードにも実装済み）
- 適用順序: NGワード判定 → URL/記号/絵文字変換（#34）→ 辞書置換 → 文字数制限
  - NGワードは整形前に判定する（変換後に判定すると意図しないマッチが起きうる）
- `maxTextLength` の `coerceAtLeast(1)` で0以下の設定値を防ぐ
