# Issue #12: SettingsScreen（設定画面）の実装

Labels: v1.2, ui

GitHub Issue: https://github.com/sahya/comerune/issues/12

Epic: #1

## Goal

読み上げエンジン選択、音声パラメータ、フィルタ、デバッグモード等の設定画面を作り、`shared_preferences` で永続化する。

## Scope

- 設定画面のレイアウト（セクション分割、スクロール可能）
- 読み上げセクション: 自動読み上げ ON/OFF、エンジン選択（ラジオボタン）
- 棒読みちゃんセクション: ホスト、速度、音程、音量、声質（エンジン選択に応じて表示/非表示）
- VOICEVOX セクション: 話者、話速、音高、抑揚、音量（エンジン選択に応じて表示/非表示）
- 読み上げキューセクション: キュー上限、最大遅延
- 読み上げフィルタセクション: URL省略、連投抑制、NGワード
- コメント表示セクション: 過去コメント取得件数（100/500/1000/全部）
- デバッグセクション: デバッグモード ON/OFF
- `shared_preferences` による永続化
- 保存タイミング: トグル/ラジオ/ドロップダウンは即時保存、テキスト入力はフォーカス喪失時に保存
- バリデーション（数値範囲チェック、エラーメッセージ表示）
- CommentScreen のオーバーフローメニューからの遷移

## Non-scope

- VOICEVOX 話者一覧の動的取得（Issue #14 の中で対応）
- 各設定値の実際の適用（各エンジン Issue で実装）

## Dependencies

- Issue #10（CommentScreen — 遷移元）

## Acceptance Criteria

- [ ] 設定画面がオーバーフローメニューから開ける
- [ ] エンジン選択に応じてセクション表示が切り替わる
- [ ] 全設定項目が表示・編集できる
- [ ] 設定がアプリ再起動後も保持される
- [ ] 数値バリデーションが動作する（範囲外入力でエラー表示）
- [ ] トグル/ラジオ変更が即時保存される
- [ ] テキスト入力がフォーカス喪失時に保存される
- [ ] 接続中でも設定変更可能

## Validation / Error Handling

- 数値フィールドに非数値が入力された場合はエラーメッセージ表示、保存しない
- 数値が範囲外の場合はエラーメッセージ表示、保存しない

## Test Expectations

- **unit**: なし
- **widget**: 設定画面の表示/遷移、エンジン選択でのセクション切替、バリデーション、永続化
- **integration**: なし

## Assumptions

- VOICEVOX 話者のドロップダウンは、話者一覧の動的取得が Issue #14 で実装されるまでは、仮の固定リスト（ID=0 のみ）を使用する
