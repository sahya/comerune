# コメント読み上げパイプライン概要

コメントが投稿されてからスピーカーで再生されるまでの処理フローを示す。

## 処理フロー

```
コメント到着
    │
    ▼
フィルタ(不要コメント除外)
    │
    ▼
テキスト整形
    │
    ▼
待ち行列(先着順)
    │
    ▼
チャンク分割(長文を自然な区切りで分割)
    │
    ▼
音声合成 ←── 再生中に次の合成を並行実行
    │
    ▼
再生
```

## 各ステップの役割

| ステップ | 役割 |
|---------|------|
| フィルタ | 読み上げ不要なコメントを除外する |
| テキスト整形 | 読み上げに適した形にテキストを変換する |
| 待ち行列 | コメントを到着順に並べ、順番に処理する |
| チャンク分割 | 長い文を自然な区切りで分割し、最初の部分から早く再生を始められるようにする |
| 音声合成 | テキストを音声データに変換する |
| 再生 | 音声データをスピーカーから出力する |

## 並行処理(パイプライン)

再生中に次の音声合成を並行して行うことで、コメント間・チャンク間の待ち時間を短縮している。

```
時間の流れ →

コメントA:
  [合成]  [再生        ]
             ↑ 再生中に次の合成を開始

コメントB:
           [合成]  [再生        ]
                      ↑ 再生中に次の合成を開始

コメントC:
                    [合成]  [再生    ]
```

長文の場合も同様に、チャンク単位で合成と再生を重ねて実行する。
