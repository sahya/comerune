comerune

ニコニコ生放送のコメントを、手のひらの上で。

ニコニコ生放送のコメントをリアルタイムに表示する Android 用の非公式コメントビューア（コメビュ）。
画面が見られないときは、読み上げ機能で耳から追いかけられます。

ドワンゴ公式アプリではありません。ニコニコ側の仕様変更で動かなくなることもあります。コメントの取得にはニコニコアカウントへのログインが必要です。

01主な機能

  • コメントのリアルタイム表示 放送番号やURLを入力するだけで、コメントが画面に流れてきます。
  • 放送者名・番組タイトルの自動表示 いま誰の放送を見ているか、ひと目でわかります。
  • ユーザー名の表示 数字のIDではなく、名前でコメントを読めます。
  • 表示のカスタマイズ 文字サイズ、ダークモード、色覚配慮テーマに対応。
  • NGユーザー管理 コメントを長押しして、ユーザーをそのまま NG にできます。
  • VOICEVOX による音声読み上げ 端末内で音声合成。ネットワーク不要で、初回のみ音声データのダウンロード（約160MB）が必要です。

02そのほか、いくつか

主な機能のうしろに、地味だけれど効くものを少しだけ忍ばせています。

  • コメントログの保存
  • 自動再接続
  • 配信中の番組から接続
  • …ほか

詳しい話は、起動してからのお楽しみに。

03なまえのこと

読みかたは 「こめるーん」。comerune と書いて、こめるーん、です。のばす音が読みづらいときは、「こめるん」 でも。

名前は Comment（コメント）と Rune（ルーン文字）の響きをもじった造語です。コメントが画面に書きこまれていく光景と、文字を一字ずつ刻むルーンの所作が、ふしぎと重なって見えました。

「Rune」のひびきが、なんとなく好きで選んだ、というのが正直なところでもあります。理屈よりも、声に出したときの感触で。毎日呼ぶ名前として、気持ちよくあれば、と。

——親しみを込めて 「こめる～ん」 と呼ばれることも。

04使いかた

  1. 歯車アイコン（⚙）から、ニコニコアカウントでログイン。
  2. 放送番号（lv123456789）か URL を入力して「接続」。
  3. 自分の配信中番組やフォロー中の放送は、一覧からそのまま接続できます。
  4. コメントを長押しすると、ユーザー詳細やコメント履歴を確認できます。

05自分だけのコメビュをつくろう

comerune は MIT ライセンスのオープンソースです。「こんな機能がほしいな」を、フォークして自分の手で叶えてみてください。コードに詳しくなくても、AI と相談しながら改造できる時代です。

フォークしたアプリを公開するときは 「comerune」とは別の名前 でお願いします。同名のアプリが複数あると、本物がどれか分からなくなってしまうためです。

ソースコードは GitHub にあります — github.com/sahya/comerune

ストアでの公開を予定しています。もし、それまで待たずに動かしてみたい方がいらっしゃれば、リポジトリを取得してビルドする形でもお試しいただけます。
